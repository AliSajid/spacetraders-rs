# Spacetraders-rs | An attempt at playing Spacetraders.io using a Rust backend

This repository is an attempt to use [Rust](https://rust-lang.org) to create
a control-plane for the [spacetraders.io](https://spacetraders.io) API game.

This is a toy project I am building to mostly blow off steam. This document
will evolve as we build more and more stuff.
